# Public source scope

Original private deployment config, domains/email/Access identity, named image assets, photographs, collection samples, tracking URLs, automatic production deployment workflow, .dev.vars/.env, databases, outputs, dependencies, generated files and original Git history are excluded. Generic test credentials remain clearly synthetic. No new first-party license is assigned. Dependency licenses remain applicable.

The generic SVG is authored for this release. Public commercial brand spelling rules and a small set of public business/provider links remain; they do not identify the original owner. Runtime data may contain personal information in an operator's own deployment, so do not distribute databases or exports with source. GitHub account ownership is outside package anonymization.
