# Whiskey Cellar source

A whiskey inventory and tasting-request app with administrator inventory, guest accounts, approval-based pours, private tasting notes and flavor recommendations. Includes Cloudflare Worker/D1 and Node/SQLite variants.

See SETUP.md and docker/README.md for isolated setup. This release uses generic configuration and synthetic test credentials, omits original images and data, and has fresh anonymous Git history. PUBLIC-SCOPE.md documents review scope and limits.
